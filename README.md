# BST vs Linear Search (C)

## Structure
- `src/bst_search.c` - source code
- `data/input.txt` - input data
- `output/output.txt` - program output
- `docs/trace_table.md`, `docs/complexity_analysis.md`, `docs/comparison_table.md`, `docs/conclusion.md`

## Build and run
    gcc -Wall -Wextra -o bst_search src/bst_search.c
    ./bst_search data/input.txt
